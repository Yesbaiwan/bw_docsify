# GitHub 代理加速

GitHub 在国内访问不稳定，下载文件速度很慢。可以在原始下载链接前拼接代理地址来解决。

使用方式：`https://代理地址/「原始下载链接」`

例如：
`https://gh-proxy.org/https://raw.githubusercontent.com/github/gitignore/main/Python.gitignore`
