可以参考这篇文章：[Windows 字体安装](../note/dev/Windows_字体安装.md)

## 三、Cherry Studio 美化

打开设置 -> 显示设置 -> 字体设置，选择安装好的字体。

最下面的 **自定义 CSS** 里粘贴 CSS 片段，在此仓库查看 CSS 代码：[bw-cherry](https://github.com/Yesbaiwan/bw-cherry/tree/main/bw-cherry/css)，如果觉得有用，可以给我点个 Star。

注意背景图片体积较大，第一次加载会比较慢。
