## 1 前言

对普通用户来说，大家在网上见到说“翻墙”、“魔法”、“梯子”、“VPN”、“科学上网”、“代理”等通常表达的是一个意思。

常见的翻墙方式：

1. 使用某某 VPN 软件，付费或免费
   > 风险高，非常不推荐
2. 购买某平台/网站的订阅节点（俗称机场订阅）
   > 这种方式可行，是大多数人翻墙的方法。但不推荐使用商家提供的软件，建议使用下文介绍的专用代理软件
3. 自建节点
   > 最安全、最专业，大部分人不具备专业知识，这里略过
4. 在网上「捡垃圾」寻找他人分享的免费节点，筛选整合后导入代理软件使用
   > 速度大多很差、IP 质量一般，节点有效期很短，通常是万人骑的垃圾节点，折腾费心费力，需要人力维护

下面是介绍不同系统使用的代理软件，在文章的最后有放**我维护的免费节点**，导入代理软件即可使用。

由于安卓、苹果等系统的下载与设置软件的方法不一样，我没办法为每个软件都介绍使用方法。但这些软件都只需要导入链接和开启系统代理就可以使用（推荐设置中开启「按照延迟排序」功能，方便找到速度最快的节点），有问题[来 QQ 群里问](https://qm.qq.com/q/bdIlVSxujm)。

本文提到的软件都发布在 GitHub 上，请按设备系统自行挑选。注意国内访问 GitHub 几乎还是要翻墙的。如果你可以访问 GitHub，但下载软件的进度条特别慢，可以将下载链接粘贴到[这个网站中](https://gh-proxy.com)获得代理下载链接，可以实现无需翻墙下载 GitHub 上的软件。

> 注：如果你使用 Watt Toolkit 工具访问 GitHub，也许能打开网站，但下载仍然很慢。因为下载流量占大头，企业带宽、流量又很贵，所以干脆限制了下载用途。

我们的 [QQ 群](https://qm.qq.com/q/bdIlVSxujm)文件中提供并标注好了 **Windows** 和 **安卓** 系统的安装包，无法访问 GitHub 的朋友可以来群里下载。

如果你已经安装好了，可以前往第五部分：[5 免费订阅](#_5-免费订阅) 获取我分享的订阅节点。

## 4 后记

由于 GFW（Great Firewall，中国防火墙）的不断封锁，机场节点经常失效，不少机场商家基于开源项目修改后作为自己的客户端分发。部分商家也会赞助开源项目，在项目主页上投放广告或提供优惠码，作为宣传渠道之一。如果商家限制了只能在自家的客户端中使用，建议不要购买这家。

如果你看到某个开源项目页面上挂着机场广告，考虑清楚是否需要、这家是否值得购买，开源项目不为机场服务买单。
